## Releases

### v2.9.7+ext-v1.2.0 — 2026-11-05

PrusaSlicer ext v1.2.0 on upstream PrusaSlicer 2.9.7 (`version_2.9.7`): the same fork features
as v2.9.6+ext-v1.2.0 (fork-tooling, wayland, wx3.3, mmu-temp-sync, tilts-uninit,
smart-auto-supports, config-backup), unchanged — only the upstream base is new.

From upstream 2.9.7:
- security fixes: out-of-bounds write when loading 3MF files with a negative `bed_idx`, stack
  buffer overflow in the `digits()` / `zdigits()` placeholder functions, path traversal in the
  downloader (redirects restricted to HTTPS, reserved names handled);
- LibBGCode update;
- new printer option `used_filament_compensation` (hidden in the UI).

Upgrading from 2.9.6: the first start takes a configuration backup ("Before PrusaSlicer
update", named with the old version) before anything is migrated.

Build: `make` — the dependencies are rebuilt once (LibBGCode); see
`doc/How to build - Linux Wayland.md`.
