## Releases

### v2.9.6+ext-v1.2.0 — 2026-11-05

Third release of PrusaSlicer ext on upstream PrusaSlicer 2.9.6 (`version_2.9.6`). It contains
everything of v2.9.6+ext-v1.1.0.

New feature:
- **config-backup — Configuration backups**: Configuration → *Back Up Configuration…* and
  *Configuration Backups…*.
  - One zip per backup (presets, physical printers, vendor profiles, `PrusaSlicer.ini`) in a
    folder outside the configuration folder (default `~/.config/PrusaSlicer-backups`,
    changeable in the dialog); the file name carries date, version and reason.
  - Automatic backups before a PrusaSlicer version change (before any migration), before
    configuration updates and after saving presets; identical states are not stored twice,
    old automatic backups are pruned (default: keep 100).
  - History: list of changed presets between a backup and the current configuration (or two
    backups), option-level comparison in the *Compare Presets* dialog.
  - Restore with a backup of the current state first and automatic rollback on errors.
  - API keys and passwords are not stored in backups; restores keep the current values.

Build: `make` (see `doc/How to build - Linux Wayland.md`).

### v2.9.6+ext-v1.1.0 — 2026-11-01

Second release of PrusaSlicer ext on upstream PrusaSlicer 2.9.6 (`version_2.9.6`). It contains
everything of v2.9.6+ext-v1.0.0.

New feature:
- **smart-auto-supports — Support planner (layer analysis)**: a new section at the end of the
  Paint-on supports tool. "Analyse and paint" analyses the sliced layers and paints support
  enforcers only where the print needs them:
  - islands (parts that start in mid-air) and overhangs whose reach, added up over the layers,
    exceeds a limit;
  - bridges and dome / hole ceilings that hold themselves stay free;
  - made for organic supports: it prefers spots whose branches reach the build plate;
  - your own enforcers and blockers are kept and taken into account;
  - a report lists what it could not support, with a marker in the 3D view;
  - "Fix…" sets the support settings it needs, for the selected object only.

  Defaults for the Prusa MK4S with a 0.4 mm nozzle, with a safety margin (self-supporting angle
  45°, confirmed with an overhang test print). Planned support is saved in the 3MF; stock
  PrusaSlicer opens it as normal enforcers. Not in this version: long bridges are reported, not
  painted; closed cavities and part stability are not checked; one object at a time. User
  guide: `doc/fork/features/smart-auto-supports/guide.md`.

Tooling:
- **fork-tooling** — the `dev` line continues across releases (each release is merged back);
  new feature branches start from the newest release tag, so `make` works on every branch;
  `git fork-bump` and `fork-status` handle such branches.

Build: `make` (see `doc/How to build - Linux Wayland.md`).

### v2.9.6+ext-v1.0.0 — 2026-10-12

First release of PrusaSlicer ext, based on upstream PrusaSlicer 2.9.6 (`version_2.9.6`).

Features:
- **wayland** — runs natively on Wayland (GTK3 + EGL) instead of XWayland; Wayland `.desktop`
  entries for PrusaSlicer and the G-code viewer.
- **wx3.3** — built against upstream wxWidgets 3.3.3 (instead of Prusa's 3.2.6 fork): Wayland/EGL
  fixes for clipboard, drag & drop, HiDPI scaling of the 3D view, runtime GLX/EGL selection.
- **mmu-temp-sync** — MMU/SEMM toolchanges between filaments with different temperatures: early
  `M104` during unload, `M109` before the purge, so the new filament is purged at its temperature.
- **fork-tooling** — `make` builds deps and app on Ubuntu 26.04 (CMake 4, GCC 15) without the
  warning flood; About / System Info show the release, upstream base and included features;
  sending system info to Prusa is disabled.

Fixes:
- **tilts-uninit** — uninitialized values in `update_tilts_by_mode` (SLA tilt settings).

Build: `make` (see `doc/How to build - Linux Wayland.md`).
