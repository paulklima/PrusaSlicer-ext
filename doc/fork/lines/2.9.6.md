## Releases

### v2.9.6+ext-v1.0.0 — 2026-10-12

First release of PrusaSlicer ext, based on upstream PrusaSlicer 2.9.6 (`version_2.9.6`).

Features:
- **wayland** — runs natively on Wayland (GTK3 + EGL) instead of XWayland; Wayland `.desktop`
  entries for PrusaSlicer and the G-code viewer.
- **wx3.3** — built against upstream wxWidgets 3.3.3 (instead of Prusa's 3.2.6 fork): Wayland/EGL
  fixes for clipboard, drag & drop, HiDPI scaling of the 3D view, runtime GLX/EGL selection.
- **mmu-temp-sync** — MMU/SEMM toolchanges between filaments with different temperatures: early
  `M104` during unload, `M109` before the purge, so the new filament is purged at its temperature.
- **fork-tooling** — `make` builds deps and app on Ubuntu 26.04 (CMake 4, GCC 15) without the
  warning flood; About / System Info show the release, upstream base and included features;
  sending system info to Prusa is disabled.

Fixes:
- **tilts-uninit** — uninitialized values in `update_tilts_by_mode` (SLA tilt settings).

Build: `make` (see `doc/How to build - Linux Wayland.md`).
